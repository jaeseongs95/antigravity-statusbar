# Test Cases Specification v2.0 (`antigravity-statusbar`)

**Languages:** **English** | **[한국어 섹션 바로가기](#테스트케이스-명세-v20-국문)**

This document defines the pre-implementation v2.0 test cases and verification oracles for the redesigned modular `antigravity-statusbar` architecture (`docs/ARCHITECTURE_V2.md`), preserving every regression guarantee from `SB-TC-001` through `SB-TC-041` while separating suites by architectural layer.

## Test Environment & Runner

- **Runner**: Node.js built-in `node:test` + `node:assert/strict`
  - Full verification: `npm test` (`node scripts/build.js && node --test test/unit/*.test.js test/integration/*.test.js test/installer/*.test.js test/e2e/*.test.js`)
  - Fast unit loop: `npm run test:unit` (`node --test test/unit/*.test.js`)
- **Isolation Guarantee**: All suites execute exclusively inside `node:vm`, synthetic DOM fixtures, temporary directories, loopback TLS/WebSocket servers, and ephemeral headless Chromium user profiles — never mutating `~/.gemini/antigravity` or `%LOCALAPPDATA%`.
- **Standalone CI**: Zero external sibling repository checkouts are required.

## 테스트케이스 명세 v2.0 (국문)

본 문서는 `antigravity-statusbar` `v2.0.0` 전면 재설계(`docs/ARCHITECTURE_V2.md`) 구현에 앞선 사전 테스트케이스 명세입니다.

- **실행 명령**: `npm test` (빌드 후 `test/unit/*.test.js`, `test/integration/*.test.js`, `test/installer/*.test.js`, `test/e2e/*.test.js` 일괄 실행) / `npm run test:unit` (순수 단위 시험)
- **격리 및 독립성**: 형제 저장소(`antigravity-mcp-manager`, `antigravity-ko-translator`) 체크아웃 없이 단독 실행하며, 호스트 PC 설치 경로(`~/.gemini/antigravity`, `%APPDATA%`)를 변경하지 않습니다.
- **회귀 보존**: 기존 `SB-TC-001`~`SB-TC-041` 및 미해결 결함(`D-0025`, `D-0032`, `D-0034`)의 모든 불변식과 검증 오라클을 계층별 `SB2-TC-001`~`SB2-TC-012`로 누락 없이 승계합니다.
